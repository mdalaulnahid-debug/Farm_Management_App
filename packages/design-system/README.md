# @farmledger/design-system

A shared look and set of building blocks. Nothing in the core is about farming: FarmLedger's BDP Agrofarm look is one **theme**, and another product (an SMS tool, a console, a SaaS app) adds its own theme file.

## What's inside

| File | What it is |
|---|---|
| `src/tokens.css` | Brand-neutral sizes: text size, radius, gaps, row height, layers (`--z-*`), motion (`--dur`, `--ease-out`), and the compact density. |
| `src/themes/bdp.css` | The BDP Agrofarm theme: colours, fonts and shadows, in light, dark and accent (green, blue, purple, amber) versions. |
| `src/components.css` | Styles for every component, plus their phone, touch and print rules. They use tokens only. |
| `src/*.tsx` | React components: `PageHeader`, `Card`, `Kpi`, `Badge`, `Alert`, `Empty`, `Loading`, `Field`, `Input`, `Select`, `SearchBox`, `Segmented`, `Switch`, `Tabs`, `Drawer`, `Dialog`, `DataTable`, `ToastProvider`/`useToast`. |
| `tokens.json` | The same tokens as data, for sites that are not built with React, and for design tools. It is generated by `npm run tokens`. |

## Using it

```ts
import '@farmledger/design-system/tokens.css';
import '@farmledger/design-system/themes/bdp.css';   // or your own theme
import '@farmledger/design-system/components.css';
import './your-app.css';

import { DSTextProvider, ToastProvider, Card, DataTable } from '@farmledger/design-system';
```

The components' own words ("Loading…", "Close", "Previous") come from `<DSTextProvider t={(en, bn) => …}>`. Without it they are English.

Theme switches live on `<html>`:

- `data-theme="dark"`
- `data-accent="blue|purple|amber"`
- `data-density="compact"`
- `data-motion="reduce"`

## Making a new theme

1. Copy `src/themes/bdp.css`.
2. Change the values, not the names.
3. Import it instead of `bdp.css`.

The tests check that body text stays readable (contrast 4.5:1).

## Checks

`npm test -w packages/design-system` checks three things:

- `tokens.json` matches the CSS;
- every `var(--…)` that the package and FarmLedger use is defined;
- the contrast of body text.

Inside FarmLedger, people with the `settings.manage` permission can see every token and component at **/system**.
